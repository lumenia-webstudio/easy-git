Vos projets GitHub, sans chercher

Dépôts, projets favoris, notifications, demandes de fusion, versions publiées : tout ce qui compte sur GitHub, rangé dans une seule fenêtre, en français.

Vous voyez d'un coup d'œil ce qui a bougé, et vous ouvrez un projet en un clic.

Un terminal qui vous explique

Easy Git contient un vrai terminal. Les boutons Commit, Push ou Pull écrivent la commande pour vous : vous voyez exactement ce qui s'exécute, et vous apprenez en faisant.

Quand Git répond, un message clair vous dit ce que ça veut dire : envoi réussi, conflit à résoudre, branche en retard.

Installer Easy Git

Choisissez l'une des deux façons. Les deux contiennent la même application.

Installer l'application

Pour Ubuntu, Debian et Linux Mint. Easy Git apparaît ensuite dans le menu Applications, et Git est installé s'il manque.

Télécharger le paquet .deb

Puis, dans un terminal :

cd ~/Téléchargements && sudo apt install ./easy-git_1.0.0_amd64.deb

Pour désinstaller : sudo apt remove easy-git

Sans installation

Pour toutes les distributions Linux. Un seul fichier, à lancer directement.

Télécharger l'AppImage

Puis rendez-le exécutable et lancez-le :

chmod +x Easy-Git-1.0.0.AppImage && ./Easy-Git-1.0.0.AppImage

S'il ne démarre pas sur Ubuntu 22.04 ou plus récent : sudo apt install libfuse2

Les empreintes SHA-256 de chaque fichier sont publiées avec la version, sur la page des versions. Windows et macOS arrivent dans une prochaine version.

Se connecter en trente secondes

Pas de mot de passe à taper dans l'application : c'est GitHub qui vous demande votre accord.

  1. Ouvrez Easy Git et cliquez sur Se connecter avec GitHub.
  2. Votre navigateur s'ouvre sur GitHub : collez le code affiché par Easy Git.
  3. Cliquez sur Authorize. Vos projets s'affichent.

Ce qu'Easy Git fait de vos données

  • Votre accès GitHub reste sur votre ordinateur. Easy Git parle directement à GitHub, sans serveur intermédiaire.
  • Le terminal intégré est un vrai terminal, avec les droits de votre compte : ce que vous y tapez s'exécute réellement.
  • Le code est public, sous licence MIT : chacun peut le lire, le vérifier et l'améliorer.
